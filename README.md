# TapLink

Моя страница ссылок: связь в Telegram, портфолио, услуги и социальные сети.

**Открыть:** https://milyygg.github.io/TapLink/

Делаю сайты и инфографику для бизнеса. На этой странице собрал всё, что нужно, чтобы посмотреть мои работы и обсудить проект.

## Запуск

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны.

## Файлы

- `index.html` - структура и ссылки.
- `styles.css` - оформление и адаптивная версия.
- `mikhail.webp` - фотография.
- `manrope.ttf`, `font-license.txt` - локальный шрифт и его лицензия.

HTML, CSS. Публикация через GitHub Pages.
